# 辯論協議（PROTOCOL）

適用於三個 agent：`zuozhuan-pro-forgery`（正方）、`zuozhuan-anti-forgery`（反方）、
`zuozhuan-arbitrator`（仲裁者）。三者的 system prompt 都要求「先讀本檔再動筆」。

---

## 1. 命題與定義

**命題（Motion）：今本《春秋左氏傳》係西漢末劉歆（約 50 BCE–23 CE）偽造。**

學術史上的「偽造說」有兩個不同強度的版本，辯論中必須區分：

| 代號 | 內容 | 代表 |
| --- | --- | --- |
| **S（強命題）** | 先秦並無今本《左傳》。劉歆割裂《國語》等既有材料並大量增撰，憑空造出一部「傳《春秋》」的書，以佐王莽篡漢。 | 康有為《新學偽經考》（1891） |
| **W（弱命題）** | 先秦確有一部獨立史書《左氏春秋》（與《晏子春秋》《呂氏春秋》同類，本不解經）。其「傳《春秋》」的性質——解經語（「書曰」「不書」「先書」「故書」「不言」「不稱」等）、「五十凡」、部分「君子曰」——為劉歆及其後學附益改編所成；今本《左傳》之為「傳」，是劉歆的作品。 | 劉逢祿《左氏春秋考證》（19 世紀初） |

規則：
- 正方在 R1 必須明白宣告主張 **S**、**W**、或 **S∨W**（先守 S，必要時退守 W）。
- 中途退守須明言「本方自此退守 W」，仲裁者將記錄退守回合。
- 反方須同時預備對 S 與 W 的反駁；只擊倒 S 不算完勝。
- 仲裁者對 S 與 W **分別**裁決並給出信心度。

「偽造」以外的替代假說（例如吳起作、戰國魯人／晉人作、多層累積成書、漢初傳人附益但非劉歆）
屬於反方陣地；反方無須證明單一作者，只須證明「非劉歆偽造」即可。

## 2. 五回合結構

正方先發言。每回合各方一篇，共十篇。R2 起每篇必須有「回應對方」節。

| 回合 | 主題 | 各方義務 |
| --- | --- | --- |
| **R1 立論** | 宣告命題版本；提出 3–5 條編號核心論點（P1…／C1…） | 每條論點附至少一筆 [A] 或 [B] 級引文；說明「什麼證據會讓本方改變立場」 |
| **R2 交鋒一：文獻傳承與漢代學術史** | 《史記》（十二諸侯年表序、太史公自序）、《漢書》（藝文志、儒林傳、楚元王傳劉歆〈移讓太常博士書〉）、西漢《左傳》傳授譜系（張蒼→賈誼→貫公→…→劉歆）、哀帝立古文經事件、劉逢祿／康有為／崔適之論證與錢穆《劉向歆父子年譜》之反駁 | 逐條回應對方 R1；本主題新論點 |
| **R3 交鋒二：內證** | 語言學（Karlgren 1926 之語法虛詞分析與後續檢討）；曆法天文（新城新藏 vs. 飯島忠夫；日食與「日南至」）；預言失效之斷代（楊伯峻等）；解經語／「五十凡」／「君子曰」與敘事層之關係；《左傳》與《國語》文體異同 | 逐條回應對方 R2；本主題新論點 |
| **R4 交鋒三：外證** | 出土文獻（馬王堆帛書《春秋事語》、清華簡《繫年》及其他戰國秦漢簡帛）；先秦兩漢引書（《韓非子》《呂氏春秋》《戰國策》、賈誼《新書》、《韓詩外傳》《淮南子》《史記》）；劉歆的動機、能力、時間（校書年限、王莽關係、當時經生的辨識能力） | 逐條回應對方 R3；本主題新論點 |
| **R5 總結** | 不得提出新證據類型（可補新出處以支撐已提論點）；明列己方讓步；指出對方未回應之點；陳述本方最強的一條論證；重述「什麼證據會改變本方立場」 | 回應對方 R4；總結 |

回合稿寫入 `debate/transcript/R{n}-{pro|con}.md`，格式依 `debate/templates/round.md`。

## 3. 引證規範（核心）

### 3.1 每一條事實性主張都要有出處

「事實性主張」包括：某書說了什麼、某人主張什麼、某事發生於何年、某字某句在某書出現幾次。
純邏輯推演可不附出處，但推演所依賴的前提要有。

### 3.2 證據分級（必須逐筆標示）

| 等級 | 定義 | 使用限制 |
| --- | --- | --- |
| **[A]** | 本回合以 WebFetch（或 Read 本地檔）**讀到原文或所引段落**，附可用 URL | 無限制 |
| **[B]** | 以 WebSearch 結果之標題／摘要／片段確認該文獻**存在且大意相符**，未讀全文，附 URL | 可用；仲裁者酌減權重 |
| **[C]** | 依模型背景知識；本次**未能線上核實**（含 WebFetch 被擋） | 須寫「[C] 未核實」。不得作為任一編號論點的唯一支撐；不得引頁碼 |

WebFetch 被 egress proxy 拒絕時，改以 WebSearch 取得同一文獻的摘要／片段，降級為 [B]；
再不能則標 [C]。**不得**因為拿不到全文而把等級往上報。

### 3.3 一手史料引用到卷篇

- 《左傳》：公＋年，例：《左傳·宣公三年》。
- 《史記》：卷名，例：《史記·十二諸侯年表序》《史記·太史公自序》。
- 《漢書》：卷數＋篇名，例：《漢書·卷三十六·楚元王傳》《漢書·卷八十八·儒林傳》《漢書·卷三十·藝文志》。
- 直接引文以「」標示，每則 **≤ 60 字**，不得改字；轉述須寫「大意」。

### 3.4 二手文獻

作者、題名、刊名／出版社、年份、卷期／頁碼（僅 [A] 級可給頁碼）、URL。
日文、英文文獻保留原題名，可附中譯。

### 3.5 禁止事項

- **禁止捏造**任何作者、題名、年份、頁碼、URL、引文字句。不確定就標 [C] 並寫「待查」。
- 維基百科、百度百科、豆瓣、博客來等只能當查找線索，**不得列入引文表**。
- 不得引用「某網友」「一般認為」「眾所周知」。
- 不得把對方的論點改寫成較弱版本再反駁（稻草人）。

### 3.6 引文表格式

每篇回合稿末附「引文表」，欄位：`編號 | 等級 | 出處（含卷篇／頁） | URL | 取得方式 | 支撐之論點編號`。
取得方式填：`WebFetch 全文`／`WebSearch 片段`／`未核實`。

---

## 4. 論證規範

- 論點編號：正方 P1, P2, …；反方 C1, C2, …；跨回合沿用，不重編。回應時寫「對 C3：」。
- 回應三態：**反駁**（給出反證）／**部分承認**（說明承認到哪裡）／**承認**。未提及 = 讓步。
- 以下招式仲裁者會點名扣分：
  1. **循環／不可否證**：以「《漢書》《史記》相關段落亦劉歆所竄」消解所有不利的漢代證據，卻無獨立證據。
  2. **訴諸權威／人數**：以「錢穆已駁倒」「學界共識」代替論證。
  3. **稻草人**、**轉移舉證責任**而不說理、**以動機代替證據**（有動機不等於有作為）。
- 允許且鼓勵：機率式推理（「若 S 為真，則應觀察到 X；實際觀察到非 X」）、對關鍵證據的可靠度做明示折價。

---

## 5. 篇幅與語言

- 每篇正文（不含引文表）**≤ 2000 字**；R1 與 R5 可放寬到 2500 字。
- 繁體中文；書名篇名人名保留原文。
- 不寫客套語、不自稱 AI、不預告「接下來我將」。

---

## 6. 仲裁規準（仲裁者用；雙方亦應知悉）

### 6.1 引證抽查（前置程序）

仲裁者對**每方至少抽查 8 筆**引文（優先抽 [A][B] 級、支撐關鍵論點者、頁碼精確者），
以 WebSearch／WebFetch 核對：(a) 文獻是否存在；(b) 是否確有所稱內容。
結果寫入 `debate/transcript/citations-check.md`。

| 抽查結果 | 處置 |
| --- | --- |
| 文獻不存在／作者題名年份明顯捏造 | 該方 −15 分／筆；該筆支撐的論點視為無證據 |
| 文獻存在但內容與所稱不符（誤引） | −8 分／筆 |
| 標 [A] 但無法讀到原文（等級虛報） | −5 分／筆 |
| 標 [C] 但實則可輕易核實而未核 | −2 分／筆 |
| 屬實 | 0 |

### 6.2 計分（各方 100 分）

| 面向 | 分數 | 說明 |
| --- | --- | --- |
| 證據真實性與可核性 | 25 | 依 6.1 扣分後之餘額；[A][B][C] 比例 |
| 證據與論點的相關性與強度 | 20 | 證據是否真的支撐所主張的命題版本（S 或 W） |
| 論證邏輯與內部一致 | 20 | 第 4 節所列謬誤每項 −3 至 −6 |
| 回應對方之完整度 | 20 | 每一條未回應之對方編號論點 −2 |
| 學術誠信 | 10 | 是否誠實標示等級、是否承認弱點、退守是否明言 |
| 表達清晰 | 5 | |

### 6.3 裁決（不是只看分數）

分數衡量「辯得好不好」；裁決衡量「命題是否成立」。兩者分開寫。

裁決書（`debate/transcript/verdict.md`，格式依 `debate/templates/verdict.md`）必含：
1. 引證抽查摘要（捏造、誤引數目；對雙方可信度的整體評語）。
2. 逐回合評述（每回合各方最強一點、最弱一點、未回應之點）。
3. 計分表。
4. **對 S 的裁決**：成立／不成立／無法判定，附 0–100% 信心度與三條主要理由。
5. **對 W 的裁決**：同上。W 須進一步分辨「有漢人附益」與「附益者為劉歆且足以稱『劉歆之作』」。
6. 學界現況陳述：主流見解為何、依據哪些文獻、辯論是否揭示了主流見解的未決之處。
7. 未決問題與可推進的研究方向（例如尚待比對的出土文獻）。
8. 對雙方的方法論建議。

仲裁者不得以「多數學者如此認為」作為裁決理由的全部；共識可列為一項證據，但須說明該共識所依據的具體論證。
